## Русский

### Claude Fable 5.1 — 4 браузерные игры, сделанные ИИ

Проекты из ролика-теста **Claude Fable 5.1**: модель по одному промпту делала мини-открытый мир, лабораторию краш-тестов, симулятор цунами и 2D-песочницу. Всё на Three.js / Phaser + React + Vite, всё запускается в браузере.

## English

### Claude Fable 5.1 — 4 browser games made by AI

Projects from the **Claude Fable 5.1** test video: from a single prompt each, the model built a mini open world, a car crash lab, a tsunami simulator and a 2D sandbox. Three.js / Phaser + React + Vite, all running in the browser.

| # | Game | Engine | AI model | Download / play |

| 2 | **Vector // Car Crash Lab**<br>3D crash-test lab: speed, mass, angle and three barrier types; impulse physics, damage, debris and a report. | Web · Three.js | Claude Fable 5.1 | [▶ Play online](https://cryptopiy.github.io/Claude-Fable-5.1-AI-Games/games/02-car-crash-lab/dist/) · [PLAY.bat](games/02-car-crash-lab/PLAY.bat) · [source](games/02-car-crash-lab) |
